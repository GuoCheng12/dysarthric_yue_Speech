# 双向混淆课程：执行前计划

2026-09-06。用户授权：先完成现有结果的调查；只有发现支持证据，才构建真实录音课程 MAS 并跑 smoke，否则停止。此任务不启动新的 ASR/TTS 训练，不修改旧 split、checkpoint、处方和历史报告。

## 待检验问题

同一个 ASR 从 zero-shot 适配后，是否出现可重复的配对现象：hard 录音中 A→B 的识别错误被真正纠正，同时 easy/medium 录音中原本正确的 B 被新错认成 A？这是转写混淆的观察性问题，不等于证明患者实际把 A 发成 B，也不证明前者因果导致后者。

## 数据与分析

- 主分析：原 zero-shot 与 real-only M0 batch8/acc4 step50，固定合并后的 511 条反馈录音。
- 重复验证：已有 real-increment 正对照 real_q 的 seed42/43/44 step50。它们均使用完整 2117 real，从原始 ASR 初始化。沿用原预测，不选择新的 best step。
- 诊断始终在同一 utt_id、同一 GT 位置配对。沿用原 Harness 的 all-optimal 字符对齐、原始文本 G2P、CER 归一化位置投影与 whole-character correctness。
- 错误消失但变成其他错字、删除或不确定对齐，不算恢复；CER 等价写法不算新 phonological error。
- 主证据仅使用上下文读音稳定、GT/hyp 只差一个 onset/nucleus/coda/tone 分量的强制替换。多分量错字另作探索性统计，不拿它替代主证据。
- 分母包括同一 GT 分量的真实载体位置；同时报告未解析/无法配对位置和整字恢复/退化，不把词典读音当声学测量。

## 继续条件（在运行结果前固定）

至少一个方向对 `(level, A, B)` 同时满足：

1. 主分析 hard 中 A→B→正确的恢复至少 5 个 GT 位置，覆盖至少 3 位患者、2 个 content、2 个不同 GT 字。
2. 主分析 easy/medium 中 B正确→A 的新增错误也满足上述 5/3/2/2 支持。
3. 在 hard 中 A→B 的真正恢复多于该签名的新错误；在 easy/medium 中 B→A 的新错误多于该签名的真正恢复。分别报告签名转为其他错误的数量，不能用签名频率下降冒充恢复。
4. 三个已有训练 seed 中至少两个重复上述双向净变化，且各有至少 3 次对应的恢复和退化。
5. 真实训练池中 A 和 B 各有至少 10 条可检索录音、3 位患者、2 个 content，能够构造不依赖 TTS 的课程。

这些阈值只是本轮是否值得继续做接口 smoke 的工程研究标准，不是显著性检验、临床诊断阈值或训练前 Meta-Utility Gate。不因结果不通过而放宽阈值或换 checkpoint 追逐阳性。

## 条件成立后才执行

保留旧 MAS，不把 TTS 处方字段改名冒充真实录音课程。实现最小独立真实课程合同，复用现有诊断、序列化和 API 路径。遵守此前准则：单一主目标；stateless 调用；instruction 解释全部数值；匿名证据；只有已存在训练录音可被选择；Harness 固定训练参数和预算；无自动重试、fallback、训练前 Gate；Reflection 仍由 Therapist 在实际结果之后执行。

拟跑三个在线接口 smoke：正常有支持证据的处方、证据不足时不强行处方、历史反馈进入下一轮处方。第三个若没有真实对应干预结果，必须明确标为合同测试夹具，不伪造 ASR 改善。模型沿用 gpt-5.6-sol/xhigh。保存完整输入/输出、校验结果、耗时与 usage，不启动 ASR 正式实验。

## 交付与停止

保存输入路径及 SHA256、全部候选/淘汰原因、逐位置证据、单元测试、可读结论。未满足继续条件则明确 STOP，不调用 Agent，不构建新 MAS。合并 511 条已经长期被用于反馈，不能称为未经查看的最终 test。
