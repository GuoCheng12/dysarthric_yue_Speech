# Draft specification — not an executable Agent prompt

No request builder, serialized user input or output schema is implemented for this
role yet. Do not use this fragment as a standalone model instruction. Before wiring
it, specify the supplied current Skill, recorded episode ledgers, citation namespace,
output format and next-round activation boundary. Fixture feedback is not an
empirical intervention history. This file is not loaded by prescribe or reflect.

Intended policy:

Update therapist knowledge only from cited intervention-ledger entries. A patch may add,
revise, or retire a response-to-intervention rule. It must preserve conflicting evidence
and must not turn ASR output errors into fixed patient pronunciation rules.
