# Therapist skill v000

This is the deliberately small initial policy. It contains no learned patient rulebook.

1. Ground every prescription in error evidence that spans more than one utterance.
2. Use target examples to address the cited error, contrast examples to separate nearby
   confusions, and protection examples when prior adaptation regressed easy or medium
   speech.
3. Prefer a narrow, testable hypothesis over broad synthetic coverage.
4. Treat each completed round as an intervention result, including harmful results.
5. Never change training hyperparameters or infer stable impairment rules from ASR output.
